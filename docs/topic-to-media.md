# 从选题到图文／视频

## 选题与素材组装

在「热点与素材」选中一个热点，进入素材组装。当前选题应始终显示同一个标题。推荐区只放相关内容；没有匹配资料时可以为空，不能用别的热门报道填满。

需要补充材料时：

- 从采集库自行选择正文，或添加笔记、报道链接。
- 点「搜索图片／视频」，搜索框会带入选题并开始搜索。可以把宽泛热点进一步改成具体物件或动作，例如把「日常美食」细化为「番茄炒蛋」。
- 也可以添加本机图片或视频。右侧是本次实际交给 AI 的资料，可断开、排序或设为重点。

图库照片和视频只是候选画面，不能证明某条新闻发生在画面中。来源、作者、许可会随素材保存；本机媒体明确标为用户选入。

## 素材来源

不需要注册图库账号或申请 API 密钥。主动资料搜索允许较早的教程、背景原文入库，保留原发布日期，并标为「参考资料」；这些资料不会进入当日新闻自动选稿。采集记录仍按七天保留。

目前公开图片／视频补充检索使用无需账号的 Commons。它只是辅助图库，不能代替热点原始素材。搜狐公开原文已经接入工作台内置浏览器读取，无需注册账号；日期、正文和正文媒体候选会一同保存。抖音和 B站的浏览器参考采集仍待接入，不能把它们写成已经支持。

2026-11-10 晚新增小红书同题图文参考采集：在官网窗口登录一次后，沿用本机浏览器会话读取公开笔记，再由本机模型提炼写法。主动采集遇到登录页会显示官网窗口；后台采集只返回登录状态。保存实际可访问的原文链接与页面显示的点赞、收藏数，按稳定笔记编号去重。当前仅接通写法案例，尚未把这些参考图片自动保存为已审核素材，也尚未实测生成新的两版完整图文。

展开带媒体的采集原文，点击「选择这篇原文的图片／视频」。这个窗口只展示所选原文的媒体，附带相邻说明和原始尺寸。可先预览，再加入右侧选题组装；GIF 会转为保留实际动作的 MP4 剪辑片段。搜狐单播放器原文还会保留浏览器实际加载的 MP4，下载后验证可解码性、时长和尺寸，不把播放器初始化文件当成原片。视频的签名参数变化不会重复保存同一原片。低清素材会标明尺寸，不放大冒充高清。来源和使用范围状态随素材保存，选中不等于获得转载授权。也可在「笔记或报道链接」粘贴搜狐公开原文，读取后使用同一个入口。

已保存媒体可从「搜索图片／视频 → 已保存素材」再次选择，即使其采集记录七天后清理，手动保存的素材仍可用于当前作品。

## 选择输出

素材组装后选择视频、图文或纯文字。纯文字只写稿；它不是完成的视频。

- 视频：正文、分章、分镜、选镜、审片和导出分步进行。实际视频素材进入选镜和裁切，图片进入动态镜头；不是把几个文案页直接冒充成片。资料不足或可用画面不足时应停在需要补充的环节。
- 小红书图文：先取得清晰、相关的实拍并通过本机看图检查，再根据画面与事实写稿。不同版本使用不同图片，保留参考案例和配图出处。缺少合适照片时不标记为完成。
