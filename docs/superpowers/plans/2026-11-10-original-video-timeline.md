# 原片时间定位 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Do not spawn parallel agents or replace another chat's release.

**Goal:** 从所选原文取得实际视频，以原片时间戳定位动作，并在 Windows 工作台内完成可核对的剪辑。

**Architecture:** 原文读取器只收集公开播放器实际加载的媒体。缓存层验证解码、时长、尺寸和来源。长视频先在本机转写出有时间戳的语音段落，再按口播检索时间窗并用视觉模型复核，最终渲染有起止点的连续片段。

**Tech Stack:** WPF / WebView2、Python、FFmpeg、faster-whisper CPU int8、现有本地 Qwen 写作与视觉模型。

**Spec:** `docs/topic-to-media.md` 与用户要求：真实视频语义裁切、可分批运行、质量优先、不发布、不要求第三方账号。

## Global Constraints

- 不把下载原文媒体等同于取得转载授权；原文出处与使用范围随素材保存。
- 不把低清放大标成高清，不把只有画面计数通过标成质量完成。
- 不修改用户草稿，不向任何平台发布。
- 正式安装包整合发布功能聊天的共享源码，不使用旧候选包覆盖。
- 只保留需要继续验证的一份原片，重复下载与临时测试包验收后清理。

## Review Focus

初始化 MP4 冒充原片、原文含多个播放器、签名参数造成重复缓存、转写幻觉、说话内容与可见动作不一致、片段结束后长时间定格。
