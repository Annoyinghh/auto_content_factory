# 小红书同题图文参考采集

用户已经要求在工作台中自动找同题图文并提炼写法，且已在官方采集窗口扫码登录。沿用现有 WPF、WebView2 和本机模型，不增加图库账号或开放平台申请。

实测公开搜索 RSS 未返回有效笔记。官网匿名搜索只显示登录提示；登录后能取得同题结果。搜索页提供的原始访问参数须保留，直接打开裸笔记编号会返回 300031。使用页面提供的链接和本机浏览器会话，已读取两篇 `normal` 图文笔记，正文 338／201 字，各 5 张图片。

实现：增加仅用于小红书参考采集的原生浏览器助手，限定官网域名，读取最多三篇同题公开笔记。浏览器登录保存在本机，后台不导出 Cookie。非交互采集遇到登录页返回明确状态，主动采集才允许显示登录窗口。正文只供本地模型提炼结构；记录原文标题、可访问链接和当次可见热度。案例检索按稳定笔记编号去重，展示保留原始可访问链接。原图先保留为来源信息，不能把它们直接标成已审素材。

验证：先测同题筛选、图文类型、稳定编号去重和浏览器返回的失败状态；再用已登录会话通过正式 worker 的采集入口取得两篇、由本机模型提炼写法，检查工作台案例库可见。整片视频任务继续使用现有会话运行，不为参考采集重启。之后统一打包、自检并核对安装包输入，排除一次性测试程序。

2026-11-10 晚间继续：原文与配图已接入 collection.sqlite3 和原文媒体入口，稳定笔记编号与 CDN 图片编号去重；短图文保留真实发布日期。自动图文分支已从通用图库改成当次同题原文，清晰度至少短边900，教程必须有过程图，未选全图在临时目录清除。各版本保留独立 source_summary 与图上文字，避免混配方。新增本机看图/OCR检查点，修改稿件可复用选图。原文推广内容不适合教程时跳过，浏览器多读一篇替换候选。
