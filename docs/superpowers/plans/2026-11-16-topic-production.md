# Hotspot to source-led weekly feature

User requests a reproducible Windows workbench action: pick a hotspot, fetch related video/photo/article/official notice sources, use reference writing structure, align speech to shots, render a complete original programme, do not publish. Latest clarification: Bilibili means a 10–15 minute weekly technology/economy feature with researched context, Whisper speech understanding and explanatory animation, not a short rapid-fire bulletin or rigid dashboard template.

## Design decisions

Reuse WPF, the existing worker, source readers, local Ollama, faster-whisper, provenance checking and FFmpeg. Add an orchestration stage invoked by the actual topic-page button. Existing work remains recoverable; candidate sources and machine review are visible. No hand-built sample scenes in acceptance, no publication calls, no unrelated stock-media fallback. Insufficient evidence or unusable video is an explicit failed/pending step, never invented duration.

Writing borrows approach from available real reference cases; factual excerpts stay separate. Weekly mode selects related recent reports and distinguishes older background. Explanatory graphics must be grounded in the cited facts and labelled; news images/footage are never fabricated. Visuals use large original media, understated chapter transitions, occasional factual timeline/data explainers and source documents, without diagonal techno decoration and repetitive panel labels.
