# 内容工厂 · 多平台短视频工作台

可自由选择题材，按平台写文案，并使用资讯采集、分镜剪辑和投稿流程。海外奇趣商业案例作为原有案例库继续提供。

## Windows 桌面版 · 内容工作台

在 Windows x64 双击 `dist\AutoContentFactory.exe`，无需另外安装 Python 或 FFmpeg。

1. **采集库**在工作台打开时每 10 分钟静默检查公开 RSS 和平台榜单。报道去重后存入 `output\collection.sqlite3`，每次采集清除超过 7 天的记录。已进入制作的选题、成片和发布记录单独保留。页面按日期展示资讯，双击标题可查看原文。
2. **平台热点**分别显示小红书、抖音和 B 站排名、热度、榜源时间与匹配报道。当前数据来自公开榜单聚合，榜源约每 30 分钟同步。**按热点制作今日版**优先选有报道的近期热点，每个平台每日最多一条，保留当天已有选题。
3. **视频制作**以 10–15 分钟的资讯合辑为目标，默认按约 12 分钟编写。每集结合 3–8 条不同热点，每章独立取材、调用本机 Ollama 编写 5–10 个分镜，再拆成短镜头。发布文案附全部来源和章节时间。口播合成后校验实际时长，超出范围时提示调整。正文或模型输出不足时提示补充。当天已有的单条稿件在开始合辑制作时存入历史记录，原有文件保留。可在制作页开启每天 08:30 的 Windows 计划任务。
4. **审片发布**可暂缓不满意的成片。**一键发布**确认当前日期的可发成片及目标账号后直接调用平台投稿接口，逐条显示审核回执。抖音和 B 站须通过 **账号与作品** 完成开放平台授权。小红书暂未接通直连接口。状态为 **待核对** 的稿件暂停重发，可在账号与作品页核对平台状态。

各环节使用按需启动的本地进程，通过选题、草稿和成片交接。草稿保存后可重复剪辑，剪辑失败可继续预览上一次的成片，AI 或素材服务故障时仍可手工编辑和使用文字卡片。

**AI 辅助和批量文案**需要本机运行 Ollama 并下载模型。将 Windows 用户环境变量 `CONTENT_AI_MODEL` 设置为本机模型名，然后重新打开程序。文案和编辑上下文只发送到本机 Ollama。[Ollama 文档](https://docs.ollama.com/)

**批量文案与案例库**支持任意题材。填写选题和已核实的事实，选择一个平台或全部平台，每批每个平台生成 1–3 版标题、口播和发布配文。程序按题材和平台检索案例写法，将摘要交给本机 Ollama。每批单独存到输出目录的 `copywriting` 子目录，文案文件附参考出处。相同题材的新批次会避开近期已生成的标题和切入点。

案例库内置 7 条公开参考，包含官方行业报告的高互动笔记、公开作品数据和榜单快照。在 **案例库 → 录入案例** 可以补充各平台的来源链接、热度依据、关键词和写法摘要。热度数字用于核对案例来源，模型只收到写法摘要。

**账号授权**适用于用自己的开放平台应用运行的 Windows 工作站。获批后在 **账号与作品 → 应用配置** 填写应用 ID、密钥、登记的回调地址，以及 B站的投稿分区 ID。保存后点击 **官方授权登录**。已有的 Windows 用户环境变量也可作为备用配置。

| 平台 | 应用配置 | 权限 |
| --- | --- | --- |
| 抖音 | `DOUYIN_CLIENT_KEY`、`DOUYIN_CLIENT_SECRET`、`DOUYIN_REDIRECT_URI` | `user_info`、`video.list`、`video.create` |
| B站 | `BILIBILI_CLIENT_ID`、`BILIBILI_CLIENT_SECRET`、`BILIBILI_REDIRECT_URI`、`BILIBILI_TID` | `ARC_BASE`，建议开通 `USER_INFO` 以显示账号昵称 |

回调地址须属于自己的应用，并与开放平台登记的地址一致。浏览器授权完成后，将完整回调地址粘贴回桌面程序。授权令牌通过 Windows DPAPI 保护。已配置的 `DOUYIN_ACCESS_TOKEN`、`DOUYIN_OPEN_ID` 和 `BILIBILI_ACCESS_TOKEN` 仍可使用。B站简介放不下完整素材署名时，可在创作者后台投稿并保留署名。

首次申请从 [抖音开放平台入驻](https://open.douyin.com/platform/resource/docs/accession-guide/platform-accession) 和 [B站网页应用接入](https://bilibili.apifox.cn/doc-885676) 开始。小红书的公开登录权限目前只包含用户基本信息，账号与作品页提供创作者后台入口。[小红书授权范围](https://openaccount.xiaohongshu.com/docs/scope)

默认订阅 36氪、爱范儿、IT之家。可将 Windows 用户环境变量 `CONTENT_NEWS_FEEDS` 设为空格分隔的 RSS / Atom 地址并重新登录。稿件由受众模板和资讯摘要生成。Wikimedia Commons 的开放照片和片段会标记为示意素材，片段静音混剪。找不到合适素材时使用分镜卡片。Edge TTS 超时时，尝试使用系统已安装的简体中文语音。

出片和日志保存在 `%LOCALAPPDATA%\AutoContentFactory`。重新打包可在项目 PowerShell 中运行：

```powershell
.\.venv\Scripts\python.exe -m pip install PyInstaller==6.22.3
.\build_windows.ps1
```

## 📂 项目工程架构

```text
auto_content_factory/
├── .venv/                      # Python 3.12 虚拟环境 (包含全套音视频依赖)
├── config.py                   # 全局配置、系统字体 (微软雅黑/黑体)、平台规格参数
├── requirements.txt            # 依赖锁定清单
├── run_web_ui.bat              # 【Windows 一键双击】启动 Web 可视化控制台
├── run_cli.bat                 # 【Windows 一键双击】启动命令行菜单
├── web_app.py                  # Streamlit 交互式工作台 (在线预览/视频播放/文案一键复制/录入新案例)
├── cli.py                      # 批处理出片与命令行调度引擎
├── core/
│   ├── database.py             # 海外奇趣商业案例库 (已内置4大多平台经典神作并支持动态扩展)
│   ├── audio_engine.py         # edge-tts 智能语音合成 + 逐句时间戳与 .ass/.srt 字幕生成
│   ├── visual_engine.py        # Pillow 高质感分镜幻灯卡片渲染 + 小红书3:4/B站16:9封面生成
│   ├── video_engine.py         # FFmpeg 自动化流水线压制 (双色描边字幕烧录 + 动态BGM自动降噪混音)
│   ├── publisher.py            # 多平台打包分发器 (生成独立文件夹、文案包、清单 manifest.json)
│   └── news_release.py         # 官方视频接口、作品列表和提交回执
├── assets/
│   └── bgm_ambient.wav         # 本地合成免版权温和氛围短视频 BGM
└── output/                     # 【全平台成品输出总目录】
    ├── pet_rock/               # 案例 01: 卖普通石头6个月赚1500万美金
    ├── irish_dirt/             # 案例 02: 把爱尔兰泥土装罐卖给美国人年销百万
    ├── glitter_revenge/        # 案例 03: 给讨厌的人寄闪粉4天狂揽两万美金
    └── million_dollar_homepage/# 案例 04: 大学生把网页切成100万像素赚百万美元
```

## 🚀 极速上手使用指南

### 方式一：启动可视化控制台（推荐小白/运营使用）

1. 双击运行根目录下的 **`run_web_ui.bat`**；
2. 浏览器会自动打开 `http://localhost:8501`；
3. 在左侧下拉菜单选择案例，可在 4 个平台的 Tab 标签页中：
   * **在线播放** 各平台专属视频；
   * **预览并下载** 小红书 3:4 封面图与 B站 16:9 封面；
   * **一键复制** 各平台专属排版好的标题、标签与笔记文案；
   * 支持切换到 **“✨ 录入全新自定义案例”** 模式，输入你自己的点子，系统自动出片！

### 方式二：命令行极速批量生产（适合程序员/定时任务）

```bash
# 激活环境
.venv\Scripts\activate

# 1. 查看已有案例库
python cli.py --list

# 2. 一键批量生成案例库中全部案例的所有平台成片
python cli.py --batch

# 3. 指定单一案例出片
python cli.py --case pet_rock
```

## 💰 商业案例变现与自媒体变现链路

在运营“海外奇趣商业”赛道时，如何实现商业闭环：

1. **流量变现（中视频伙伴计划 / 广告分成）：**
   * B站中视频与播放量收益；
   * 微信视频号流量主与分成计划。
2. **商单广告（星图 / 蒲公英 / 花火）：**
   * 粉丝积累到 1~5 万后，接数字化工具、SaaS 软件、海外跨境金融、知识付费品牌的定制植入广告。
3. **私域知识付费与商业社群（后端高客单）：**
   * 小红书与视频号引流私域微信，售卖《全球搞钱脑洞数据库》、《商业模式拆解周刊》或搞钱社群会员（客单价 199~999 元）。
4. **出海服务与外包接单：**
   * 打造“懂海外前沿商业逻辑”的个人 IP，吸引想做出海业务或独立开发的客户找你进行外包或咨询。
