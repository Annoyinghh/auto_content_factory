# 内容工厂 · 多平台视频工作台

> 当前为开发快照（2026-11-17），成片视觉效果尚未通过人工验收。安装版已能通过正常按钮生成视频，但仍需解决截图可读性、逐镜引用段落错配、动画重复和口播叙事不足的问题。自动测试通过不代表成片质量达标。

在 Windows 上从采集资讯、确认报道和编写分镜，到试剪、导出视频和审片投稿。双击 `dist\AutoContentFactory-Studio.exe` 打开 WPF 桌面工作台。分发时请使用完整压缩包，解压后保留与程序同级的 `_engine` 和 `browser_extension`。

## 从源码启动

在 Windows x64 上安装 64 位 Python 3.12。在项目根目录打开 PowerShell，确认 `python --version` 显示 3.12，再创建虚拟环境并安装依赖。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

运行 `.\build_windows.ps1` 构建 WPF 工作台，再从 `dist` 启动。旧版 `desktop.py` 可用于对照测试。

### 本地 AI

AI 辅助编稿、分镜和批量文案需要在本机运行 Ollama。安装了工作台的 `acf-writer-qwen35:9b` 时优先用它编稿；否则按本机已安装模型回退。可以将 `CONTENT_AI_MODEL` 设为指定模型，再重新启动工作台。编稿和编辑上下文通过本机 `127.0.0.1:11434` 发送给 Ollama。

多模型制作会先复核口播，画面设计优先使用已安装的 9B 写作模型，看图选镜优先使用 `acf-vision-qwen35:4b`。两个角色可分别用 `CONTENT_AI_DESIGN_MODEL` 和 `CONTENT_AI_EDIT_MODEL` 指定。原视频使用本地 faster-whisper small 识别语音与时间位置，转写仅用于定位，事实仍从原文核对。模型安装后，新稿自动走视觉流程。已保存的稿件可点「视觉设计与看图选镜」生成候选版，审片确认后再保存和导出。

## 桌面工作台

1. **数据面板**。查看今天首次采集的报道、各平台今日热点和自己的账号指标。热点按平台汇总当天观察到的去重条目，从升级后首次成功刷新开始累计。账号指标可以使用界面中的 CSV 模板导入。
2. **热点与素材**。从平台热点或采集报道打开选题，展开候选分支查看原文摘录。接入想用的报道、补充文字或本机素材，在右侧排顺序、断开分支和指定重点。公开 HTTPS 报道可通过「读取链接」补入候选。素材组装需要至少一篇可引用的正文；B 站长片需要更充分的资料。工作台会定期采集 RSS 和榜单，清理超过 7 天的采集记录。
3. **AI 创作**。点「生成试剪」后，以本次接入的资料编写和复核分镜。可以播放试剪、在时间线上打开对应镜头、调整画面与口播，保存后再导出。抖音、小红书视频可选约 1、2、3 分钟，B 站长片按实测口播校验 10–15 分钟。小红书图文和文字稿可在「批量文案」中生成。
4. **作品库**。按选题翻阅各平台的成片、试剪和笔记。小红书视频、图文笔记和文字稿各自保留。

桌面版可按需开启每天本地时间 08:30 的 Windows 计划任务。任务生成的成片会进入审片队列。

## 审片与投稿

「团队运营」可以登记共享账号备注、同步投稿进度，也可以把确认过的摘要交给团队中开启接单的 Ollama 电脑处理。个人采集库、成片和平台登录保留在本机。见[团队运营部署](docs/cloudflare-operations.md)。

在「作品库」点「投稿」，发布中心会带入对应作品，并沿用上次使用的本机个人账号。首次有多个账号时，先选账号再点投稿。可以在发布中心暂缓或恢复成片的发布资格。

如果团队已开通共享服务，点「送团队审片」可上传这版成片和文案。同事在 Windows 桌面版的「团队审片」里按标题、提交人或审核状态查找成片，也可以播放、留言或作出审核决定。异地连接使用个人连接码和统一的 HTTPS 地址。见[团队审片部署](docs/team-deployment.md)。

- **抖音**：在「矩阵账号」添加个人号，首次登录时在面板内扫码。每个号有自己的本机登录会话。投稿时，工作台内的面板会放入视频并尝试填写文案。请核对实际账号、上传进度、封面和发布设置，再点「发布」。
- **小红书**：在「矩阵账号」添加个人号并扫码。视频和图文均可从「作品库」投稿。工作台会将视频或整组图片及文案交给内置面板，核对后在面板内发布。
- **B 站**：在 Chrome 148 或兼容版本中加载 EXE 旁的 `browser_extension` 文件夹，再登录创作者后台。选中成片后点「填入投稿页」，核对内容后在浏览器中发布。

工作台的填稿状态表示投稿页接到了素材，平台是否受理以创作者后台为准。

### 平台与账号

| 平台 | 成片画幅 | 投稿方式 |
| --- | --- | --- |
| 抖音 | 9:16 | 在工作台内登录、上传和确认 |
| B 站 | 16:9 | 填入浏览器投稿页并在平台确认 |
| 小红书 | 9:16 | 在工作台内登录、上传和确认 |

已有获批应用也可以使用「开放平台投稿」。抖音成片超过 128 MB、B 站成片超过 100 MB 时自动分片，合并后提交审核。单个视频最大为 4 GB。状态为「待核对」时，请先到创作者后台核对。

在「账号与作品 → 应用配置」填入自己的开放平台应用信息，再点击「官方授权登录」。使用与平台登记一致的回调地址，授权完成后将完整回调地址粘贴回工作台。应用配置和令牌使用 Windows DPAPI 保护。

| 平台 | 可用的环境变量 | 应用权限 |
| --- | --- | --- |
| 抖音 | `DOUYIN_CLIENT_KEY`、`DOUYIN_CLIENT_SECRET`、`DOUYIN_REDIRECT_URI` | `user_info`、`video.list`、`video.create` |
| B 站 | `BILIBILI_CLIENT_ID`、`BILIBILI_CLIENT_SECRET`、`BILIBILI_REDIRECT_URI`、`BILIBILI_TID` | `ARC_BASE`，建议开通 `USER_INFO` 以显示昵称 |

## 批量文案

在「平台热点 → 小红书」选一条北京时间今日的热点，选择 2 版或 3 版，再点「写小红书文案」。工作台先找可读的同题案例、提炼写法入库，再按各版的切入点匹配写法，生成正文和配文。默认只出文字。在「AI 创作 → 批量文案」勾选「小红书热点配图」后重新生成，可出 4–6 张 1080×1440 JPG。封面资料照片附作者和授权记录，旅拍内页按动作生成可区分的示意图，其他内页用文字排版。可在版本下拉框查看本版采用的写法及出处。

在其他平台可点「用热点写文案」，也可以在「AI 创作 → 批量文案」填写团队已核实的素材。批次保存在 `output/copywriting/`。

选定一个平台和选题后，可点「采集同题案例」查找公开作品。也可以在「案例库」粘贴一条完整作品链接，或录入团队可访问的参考片段。程序只把能读到的公开作品文案交给本地 AI，保存写法摘要、采集时间和出处。写稿优先检索同平台同题材作品，报告事实和写法出处分别列出。

工作台在后台轮换检查各平台近期热点。匹配到报道时保存带原文出处的摘录，读到同题公开作品时提炼其写法。团队手上已有的片段可从「录入案例」加入自动学习队列，提炼成功后移除队列中的原片段。案例库会显示该平台最近一次检查的时间和结果。已过期的热点报道摘录定期清理，长期写法案例继续供检索。

## 数据位置与可选打包

| 运行方式 | 数据根目录 |
| --- | --- |
| 源码运行 | 项目根目录 |
| 打包版 | `%LOCALAPPDATA%\AutoContentFactory` |

采集库、草稿和成片写到数据根目录下的 `output/`。克隆仓库并安装依赖后，可以运行打包脚本自行构建 Windows EXE。

```powershell
.\.venv\Scripts\python.exe -m pip install PyInstaller==6.22.3
.\build_windows.ps1
```

构建使用 Windows 的 .NET Framework 4.8 工具和项目虚拟环境。发布包的 WPF 窗口直接启动，`_engine` 内含 Python 后台、FFmpeg 和抖音投稿面板，使用者无需另装 Python。抖音投稿面板需要 Windows 的 Microsoft Edge WebView2 Runtime。同目录有 `local-ai` 时，工作台可启动其中的 Ollama。
