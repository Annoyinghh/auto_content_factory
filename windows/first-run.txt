热采放映室 Windows 工作台

适用 Windows 10／11 x64，需系统 .NET Framework 4.8 或更新版。
完整解压后双击 AutoContentFactory-Studio.exe。请保留同级 _engine 和 browser_extension。
稿件、采集库和账号保存在当前 Windows 用户的本机数据目录。

首次体验可从「热点与素材」刷新采集，或在「AI 创作」右上角搜索图片和视频素材。
在「矩阵账号」添加抖音或小红书个人号，选中账号后在工作台内扫码。
在「作品库」点「投稿」，发布中心会带入这份作品并沿用上次使用的本机账号。首次有多个账号时请先选一个。
抖音和小红书会在内置面板填入素材和文案。请在面板核对账号、内容和上传状态，再点发布。

AI 试剪需要本机 Ollama 和可用模型。已有便携 local-ai 可放到 EXE 同级；也可以由有模型的同事在团队空间开启接单。
团队协作使用管理员提供的 HTTPS 地址和个人连接码。创作者投稿面板需要系统 WebView2。
